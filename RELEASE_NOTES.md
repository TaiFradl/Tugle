# Tugle 2.3

Workspaces, split view, faster navigation, and a cleaner browser interface.

## What's new

- Separate workspaces with their own tabs, startup pages, colors, search engine, and privacy preferences.
- Colored tab groups with collapse/expand, multi-tab selection, drag-and-drop grouping, and automatic grouping rules.
- Workspace templates, import/export backups, and memory controls for sleeping tabs.
- Command palette (`Ctrl+Shift+P`) to find actions, tabs, workspaces, and recent pages, with improved search ordering and clearer empty results.
- Split view (`Ctrl+Shift+S`) to use two tabs side by side. Drag the divider to resize; double-click it for equal widths.
- Smart link routing to send websites to a chosen workspace or group. Configure it from the workspace switcher.
- Simpler settings, improved bookmark icons, and consistent Google, DuckDuckGo, and Bing search.
- Clearer audio controls appear only on playing or muted tabs.
- Search, edit, and manage bookmarks. Read later has been removed; its saved links remain as bookmarks.
- Most-used sites replace recent sites on Home.
- Restored background tabs load when selected, reducing startup work. History saves are batched, and unchanged Home backgrounds no longer reload on tab switches.
- Tighter toolbar spacing, content-sized panels, improved scaling, and a new Slate theme in setup and settings.
- Duplicate, pin, mute, reopen, and scroll through tabs. Sessions restore the previous tab order and selection.
- Saved custom theme colors, private windows, privacy controls, packaged ad blocking, download controls, and Save as PDF.

## Install or update

Download **Tugle-Setup.exe** for the Windows installer with Start Menu and optional desktop shortcuts. **Tugle-browser.zip** remains available for portable use and older versions' update prompts.

Tugle checks for updates when it opens, or from Settings → Browser settings → Check for updates. Installed versions with the newer updater download the installer and ask before restarting. Older and portable versions offer a download. This release is published as **v2.3.0**, which older versions recognize as an update. Existing local settings, bookmarks, and website data are preserved by the installer.

Windows x64 and Microsoft Edge WebView2 Runtime are required. Settings and bookmarks stay local to your device; there is no cross-device sync.
